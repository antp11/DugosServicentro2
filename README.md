# Dugo's Servicentro #2 – Website

Responsive website for an auto service center, focused on preventive maintenance, oil changes and car care.

🔗 **Live site:** https://antp11.github.io/DugosServicentro2/

## Pages
- **Home** – Services overview and car care tips
- **Services** – Oil types, filters and maintenance services
- **About** – Company information and FAQ
- **Location** – Map and current weather
- **Contact** – Contact details and social media
- **Author** – Project credits

## Features
- Responsive layout for desktop and mobile with Bootstrap
- Reusable components (navbar, footer, cards)
- Dynamic content loaded with JavaScript from JSON files (work gallery, data)
- Weather information on the location page

## Tech stack
HTML5 · CSS3 · JavaScript · Bootstrap
